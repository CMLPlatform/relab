This page describes the files in a published [dataset release](/project/dataset/): what each
column holds, what its absence means, and where it should not be over-read. It is generated
from the release schemas in `backend/scripts/build_dataset_release.py`, so it describes the
archive the build actually produces rather than the platform's internal database. For the
internal schema, see [Data model](/architecture/datamodel/).

Every release also carries `croissant.json`, the same field descriptions in
[MLCommons Croissant](https://mlcommons.org/working-groups/data/croissant/) form, for tools
that read dataset metadata directly.

## How to read the tables

- **Required** means the column is never null. Everything else can be null, and null means
  "not recorded" rather than zero or empty. A missing `weight_g` is a product nobody weighed,
  not a weightless product.
- Identifiers are unique within one release, and reference tables are joined by them.
- `records.parquet` holds both whole products and their components in one table. A row with a
  null `parent_id` is a whole product; anything else is a part taken out of the row named by
  `parent_id`. Depth is not bounded, so treat it as a tree, not two levels.
- Reference tables under `reference/` are frozen copies taken at build time. They are the
  vocabulary the records were annotated against, not a live taxonomy.

## Contributor identity

`owner_pseudonym` is the only trace of who recorded a row. It is a salted hash, the salt is
not published, and contributors are credited collectively in the release `README.md` rather
than individually.

The same contributor keeps the same pseudonym across releases, which is what makes
longitudinal work possible — but only across releases built with the same salt. Each release
publishes a pseudonym salt fingerprint in its `README.md`; two releases whose fingerprints
match have comparable pseudonyms, and two that differ do not. Check the fingerprint before
joining on `owner_pseudonym` across releases.

Re-identifying contributors falls outside both the licence and the basis the release was
published on.
